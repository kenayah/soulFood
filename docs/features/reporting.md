# Reporting

## Introduction

Reporting provides insights into business performance through daily, weekly, and monthly reports for informed decision-making.

## Report Types

### Daily Reports

Generated automatically at end of day (or on demand):

| Metric | Source |
|---|---|
| Orders completed | `orders WHERE status = delivered AND date = TODAY` |
| Total revenue | `SUM(order.total) WHERE date = TODAY AND status = delivered` |
| Popular dishes | `order_items GROUP BY menu_item_id ORDER BY qty DESC` |
| Peak hours | `orders GROUP BY hour(created_at)` |
| Average order value | `AVG(order.total) WHERE date = TODAY` |

### Weekly Reports

Generated every Sunday evening:

| Metric | Source |
|---|---|
| Week-over-week comparison | Current week vs previous week revenue |
| Top 5 dishes | By quantity ordered |
| Stock usage | Ingredients consumed (by recipe association) |
| Customer trends | Repeat vs new customers |

### Monthly Reports

Generated on the 1st:

| Metric | Source |
|---|---|
| Revenue summary | Total, by payment method, by day of week |
| Profit estimates | Revenue - (ingredient costs estimated) |
| Menu performance | Best and worst selling items |
| Cost analysis | Ingredient spend per supplier |

## API Endpoints

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/reports/daily?date=2026-06-01` | Daily report for given date |
| `GET` | `/api/reports/weekly?week=2026-W23` | Weekly report |
| `GET` | `/api/reports/monthly?month=2026-06` | Monthly report |
| `GET` | `/api/reports/dashboard` | Summary stats for admin dashboard |

## Data Aggregation

Reports are generated by querying D1 with aggregation functions:

```sql
-- Daily revenue
SELECT DATE(created_at) as day,
       COUNT(*) as order_count,
       SUM(total) as revenue,
       AVG(total) as avg_order_value
FROM orders
WHERE status = 'delivered'
  AND DATE(created_at) = ?
GROUP BY DATE(created_at)
```

## Decision Support

Reports help with:

- **Pricing** — Are margins sufficient? Raise prices on low-margin items
- **Menu changes** — Drop poor performers, promote best sellers
- **Staff scheduling** — Staff up for peak hours identified in reports
- **Marketing** — Promote slow days with specials
- **Supplier negotiations** — Volume data for bargaining
